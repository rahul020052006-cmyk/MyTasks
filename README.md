MyTasks — Flux8labs MERN Internship

This repository contains the practical projects completed as part of the Flux8labs Web Development Internship. The tasks cover progressive web development concepts, starting with server-side forms and validation and progressing to React CRUD applications, REST APIs, MongoDB authentication, JWT, and Role-Based Access Control (RBAC).

📂 Projects Included
Task 1 — Form Demo

An Express.js and EJS application demonstrating server-side rendering, form submission, and dynamic data rendering.

Task 2 — Form Validate

A server-side form validation project using express-validator for input validation, sanitization, and structured error responses.

Task 4 — Complex Form

A frontend project built with HTML, CSS, and JavaScript featuring dynamic DOM manipulation, hash-based routing, real-time validation, password strength checking, and form progress tracking.

Task 5 — My CRUD App

A full-stack product management application with a React + Vite frontend and Node.js + Express REST API backend. It supports GET, POST, PUT, and DELETE operations with Axios-based API communication.

Task 6 — AuthApp

A backend authentication system using MongoDB, Mongoose, bcrypt, JWT, cookies, and RBAC. It provides secure registration/login workflows and protected routes based on user roles.

🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript, React 19, Vite
Backend: Node.js, Express.js, EJS
Database: MongoDB, Mongoose
Authentication: JWT, bcrypt, HTTP-only cookies
API & Tools: REST API, Axios, CORS, Nodemon, Git, npm
🚀 Getting Started
git clone https://github.com/rahul020052006-cmyk/MyTasks
cd MyTasks

Navigate to the required project folder, install its dependencies, and follow the project-specific README for the complete setup and run instructions.

Most Node.js projects can be started with:

npm install
npm run dev

For projects requiring MongoDB, configure the required environment variables such as the MongoDB connection URL and JWT secret before starting the server.
